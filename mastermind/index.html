How to play

Choose a color for each of the four positions. Colors may repeat. Each guess gives two counts:

  • Exact: right color, right position.
  • Elsewhere: right color, wrong position.

Each peg counts once. Feedback does not identify individual positions. Four exact matches solve the code.

Use the four color menus with a mouse, touch, or keyboard. Numbers identify colors as well, so you do not have to distinguish them by sight.

In “Set a code,” choose a secret and lock it in. Advance the computer one guess at a time; feedback is scored automatically.

    From Swift to the browser

    This version adapts Andur Carr’s original Swift implementation, including its code generator, duplicate-aware scoring, twelve-turn game, and Knuth-style minimax solver. The JavaScript translation and browser interface were built with AI assistance.

    The solver begins with two pairs, then keeps every code consistent with the feedback. It considers all 1,296 guesses and picks the one that leaves the smallest possible worst-case set of answers. Ties favor a possible answer. This version uses a fixed color order to make ties reproducible, where the Swift version chooses randomly.

    “Minimax” describes the next-guess objective, not a claim of globally optimal average play. The included exhaustive check tests every possible secret. The solver runs in a Web Worker and receives only previous guesses and their feedback—not the secret.

    Everything runs in your browser. No account, backend, or AI API is used. A new round or page reload starts fresh.
