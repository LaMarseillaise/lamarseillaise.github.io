A game in the console

Open your browser’s developer console on this page, the homepage, or the Mastermind page. The emoji palette and red/white grades come from my original Swift console interface. Commands replace the terminal input loop; the existing compiled Swift/WebAssembly solver supplies minimax guesses.

andur.help()
await andur.play("mastermind")
andur.guess("1123")
andur.board()
await andur.hint()
andur.quit()

// Make a code and watch the computer break it:
await andur.make("6654")

// Or explicitly choose the JavaScript solver:
await andur.play("mastermind", {engine: "javascript"})

The palette is 1 ⚫️, 2 🔵, 3 🟢, 4 🔴, 5 ⚪️, 6 🟡. Codes contain exactly four digits; repeats are allowed. A hint submits a guess. Grades are unordered: red means the right color in the right position, white means the right color in another position. There are twelve attempts.

Emoji widths vary by browser and font. Use andur.board("text") for letters and numbers. Console rounds have their own state and worker; they do not change the visible game. Reloading clears them. The solver loads only when needed, and receives only guesses and feedback, never the hidden code. No account or AI service is involved.

Where to look next

The project catalog is plain JSON. await andur.projects() prints the demo and source links as a console table. The project directory is the human-readable version.

  • Mastermind: an adaptation of my original Swift game, with interchangeable JavaScript and compiled Swift solvers. The implementation and verification notes describe exhaustive scoring and decision-tree checks. Those checks cover this fixed four-peg, six-color game.
  • SQL Join Explorer: an interactive explanation of inflated totals from joins. Its verification notes describe comparisons with SQLite across twelve input sets—a concrete example of independently checking AI-assisted output.
  • Latin, connected: a reading and annotation tool connecting grammar and reference to an explanation of transformer attention. The connections are reader-authored; they are not model-generated attention weights. Source and limitations.
  • One problem, many languages: editable JavaScript, Ruby/Wasm and Python/Wasm, with other languages presented as references. It distinguishes runnable environments from examples. Runtime details and checks.

About this collaboration

I direct these projects and use AI assistance in their implementation and documentation. Some adapt earlier work of mine; project notes identify those origins and the checks actually performed. The distinction between an idea, a generated implementation, and verified behavior matters to me. Code as a reviewable receipt explores that theme.

Around 1994, my sister and I discovered that a game called Land of the Fuzzies, built with HyperCard, was easy to modify. We began making our own games. I still want software creation to feel that approachable.
